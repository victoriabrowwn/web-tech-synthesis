# Gather — event ticketing demo

Built with plain HTML, CSS, and JavaScript. 

Features: six illustrative events, search, category and date filters, event details, quantities from 1–8, calculated GHS totals, simulated bookings, browser-local booking history, and downloadable HTML tickets that can be printed or saved as PDF.

Files: `index.html` (page), `style.css` (responsive design), `java.js` (data and behaviour).
